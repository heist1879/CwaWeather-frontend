# Linear Finch

Personal travel planner for **NYC · Boston · Banff** (May 30 – Jun 22 2026).

- **Schedule view** — day timeline with admission fees, opening hours, free-entry windows, and discount notes
- **Map view** — today's stops plotted on an interactive OpenStreetMap with a route polyline
- **Toggle** — pill button to switch between Schedule and Map
- **Offline-ready** — cached via Service Worker; works in Banff dead zones
- **PWA** — installable on iPhone and Android from the browser

## Deploy

These 4 files are a complete standalone app — no build step needed.
Just serve `index.html` from any static host (GitHub Pages, Netlify, Vercel).
